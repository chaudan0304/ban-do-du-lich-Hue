# Khoa_luan

Xây dựng website khám phá địa điểm du lịch sử dụng Graph Database và hệ khuyến nghị

- Tập trung vào PageRank và Thuật toán Collaborative Filtering (Lọc cộng tác - Graph Based) => Hệ gợi ý lai (Hybrid Recommendation System) theo chiến lược Xếp hạng phân tầng (Tiered Sorting).
- Độ tương đồng trong neo4j
