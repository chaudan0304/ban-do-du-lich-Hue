## Danh mục thuật ngữ

| Thuật ngữ | Giải thích |
|---|---|
| Cold Start | Vấn đề khởi động lạnh — hệ thống gợi ý không thể đưa ra gợi ý chính xác cho người dùng mới hoặc item mới do thiếu dữ liệu tương tác. |
| Cypher | Ngôn ngữ truy vấn khai báo dành riêng cho CSDL đồ thị Neo4j, tương tự SQL cho RDBMS. |
| Damping Factor | Hệ số tắt dần trong thuật toán PageRank, biểu diễn xác suất người dùng tiếp tục duyệt đồ thị thay vì nhảy ngẫu nhiên (thường bằng 0.85). |
| Filter Bubble | Bẫy bong bóng lọc — hiện tượng hệ thống chỉ gợi ý nội dung tương tự với sở thích cũ, hạn chế khám phá nội dung mới. |
| Graph Database | Cơ sở dữ liệu đồ thị — loại CSDL sử dụng cấu trúc đồ thị (đỉnh, cạnh, thuộc tính) để lưu trữ và truy vấn dữ liệu. |
| Graph Traversal | Duyệt đồ thị — kỹ thuật di chuyển qua các node và relationship trong đồ thị để tìm kiếm hoặc phân tích dữ liệu. |
| Haversine | Công thức tính khoảng cách giữa hai điểm trên bề mặt hình cầu (Trái Đất) dựa trên tọa độ kinh vĩ độ. |
| Hybrid Recommendation | Hệ thống gợi ý lai — kết hợp nhiều phương pháp gợi ý (CF, CBF, PageRank) để tăng độ chính xác. |
| Index-Free Adjacency | Tính chất của Neo4j: mỗi node lưu con trỏ trực tiếp đến các node lân cận, giúp duyệt đồ thị O(1) mỗi bước. |
| Jaccard Similarity | Độ đo tương đồng Jaccard — tỷ lệ giữa phần giao và phần hợp của hai tập hợp, giá trị từ 0 đến 1. |
| Labeled Property Graph | Mô hình đồ thị có nhãn và thuộc tính — mỗi node/relationship có nhãn phân loại và các cặp key-value. |
| Nearest Neighbor | Thuật toán Láng giềng gần nhất — chiến lược tham lam chọn điểm gần nhất chưa đi qua, dùng để xấp xỉ bài toán TSP. |
| Node | Đỉnh trong đồ thị — đại diện cho một thực thể (người dùng, địa điểm, danh mục). |
| Node Similarity | Thuật toán đo độ tương đồng giữa các node dựa trên tập các node lân cận chung (sử dụng Jaccard Index). |
| PageRank | Thuật toán đánh giá mức độ quan trọng của node trong đồ thị dựa trên số lượng và chất lượng liên kết đến nó. |
| Relationship | Cạnh trong đồ thị — biểu diễn mối quan hệ có hướng giữa hai node (ví dụ: :LIKED, :REVIEWED). |
| Serendipity | Khả năng gợi ý những item bất ngờ nhưng phù hợp, nằm ngoài sở thích trực tiếp của người dùng. |
| Swimlane | Đường bơi — kỹ thuật phân chia sơ đồ hoạt động theo vai trò (User, System, Admin). |
| TF-IDF | Kỹ thuật đánh giá mức độ quan trọng của từ trong văn bản dựa trên tần suất xuất hiện và tần suất ngược trong tập tài liệu. |
| Weighted PageRank | Biến thể PageRank cho phép các cạnh có trọng số khác nhau, phản ánh mức độ tương tác (Like=1.0, Review=1.0–5.0). |
