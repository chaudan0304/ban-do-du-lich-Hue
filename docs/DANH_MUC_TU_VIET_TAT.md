| API | Application Programming Interface | Giao diện lập trình ứng dụng |

| CF | Collaborative Filtering | Lọc cộng tác |

| CRUD | Create, Read, Update, Delete | Tạo, Đọc, Cập nhật, Xóa |
| CSRF | Cross-Site Request Forgery | Giả mạo yêu cầu xuyên trang |
| CSS | Cascading Style Sheets | Bảng định kiểu xếp tầng |
| DAL | Data Access Layer | Tầng truy cập dữ liệu |
| GDS | Graph Data Science | Khoa học dữ liệu đồ thị |

| IDE | Integrated Development Environment | Môi trường phát triển tích hợp |

| PK | Primary Key | Khóa chính |

| TSP | Traveling Salesman Problem | Bài toán người bán hàng |

| UC | Use Case | Trường hợp sử dụng |

| URL | Uniform Resource Locator | Định vị tài nguyên thống nhất |
| WSGI | Web Server Gateway Interface | Giao diện cổng máy chủ web |
